A simple but fun C# console game where the player guesses the absolute difference between the diagonals of a randomly generated square matrix.
The game runs over 5 rounds, gives feedback based on guess accuracy, and tracks the player's score.

This project helped me practice working with:
2D lists (List<List<int>>)
Looping structures
Random number generation
Basic game logic
Clean console output formatting
I'm planning to expand this into a Blazor web app in the future.
